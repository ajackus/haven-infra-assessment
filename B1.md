# B1 — The Glacier cost gotcha

The Terraform storage class `GLACIER` represents S3 Glacier Flexible Retrieval,
which has a **90-day minimum storage-duration charge**. The object transitions
on day 30 and is deleted on day 40, so it has spent only 10 days in that class.
Deleting it early does not avoid the minimum: AWS charges for the remaining
**80 days** of the 90-day minimum storage duration.

For an object of size `S` GB and a regional Glacier Flexible Retrieval rate
of `R` dollars per GB-month, the approximate early-deletion storage charge is:

```text
S × R × (80 / 30)
```

This is the prorated charge for the unelapsed portion of the minimum duration;
the exact amount depends on object size, region, and the applicable rate. It is
separate from ordinary request or retrieval charges that may apply.

The seller deletion request must be completed within 30 days. Simply postponing
physical deletion until day 120 would avoid the Glacier minimum-duration charge,
but would violate that deletion deadline.

**Redesign:**

1. Treat a seller deletion request as an application-level state transition:
   immediately mark the listing and its photos inaccessible, revoke signed
   URLs/caches as appropriate, and create an auditable deletion job.
2. Complete physical deletion within the required 30-day SLA. Do not hold
   deletion-requested objects merely to wait out a storage minimum.
3. Do not transition objects subject to on-demand deletion into a storage class
   with a minimum-duration commitment. Keep them in S3 Standard (or another
   class whose economics and minimum-duration rules have been verified).
4. Use Glacier only for a separate archive population whose retention policy
   guarantees that each object will remain stored for at least the class's
   minimum duration. Enforce eligibility before applying an archive tag or
   transition.
5. Track deletion requests, completion timestamps, archive eligibility, and
   early-deletion charges. Alert on SLA breaches and unexpected storage costs.

The core correction is architectural: if an object can legitimately be deleted
at any time within a 30-day request window, a 90-day-minimum storage class is
the wrong default for that object. Lifecycle rules should reflect the actual
retention guarantee rather than assuming sold photos will remain archived.
