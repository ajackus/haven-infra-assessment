# B1 — The Glacier cost gotcha

What's the actual cost impact of an early deletion after archival? How would you redesign the
lifecycle so this stops quietly costing more than budgeted?

The lifecycle rule moves photos to s3 glacier after 30 days. 
That class has a 90-day minimum storage duration. If a seller requests deletion on day 40 , it has spent only 10 days in the glacier. AWS will still charge an early deletion fee for the remaining 80 days.The cost depends on the object size and the applicable rates.
I wouldn't move photos that can be deleted with such extra cost.
I will use s3 intelligent tiering and use glacier only when we can get a guarantee that the photos will stay for at least 90 days.
If glacier is still required we should budget and alert on early deletion charges instead of letting them go unnoticed.
